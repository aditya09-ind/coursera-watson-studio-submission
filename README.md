📄 Project Overview

This repository contains the Jupyter Notebook for the lab “Extracting and Visualizing Stock Data”, completed as part of an IBM / Coursera course.
The goal of this lab is to:
Collect stock data using an API and Webscraping
Clean and prepare the dataset
Visualize trends using plots
Compare stock performance over time
The notebook demonstrates the use of Python, Pandas, yFinance (or provided functions), and Matplotlib to retrieve and analyze stock market data.

🧪 Contents
*.ipynb — Jupyter Notebook with all code, results, and visualizations
Code for:
Data extraction
Data cleaning

Graphing and visualization

Matplotlib / Seaborn
yFinance or custom data-extraction utilities (depending on environment)

🚀 How to Run the Notebook
1. Clone or download the repository
2. Open the notebook in:
Jupyter Notebook
JupyterLab

IBM Watson Studio
3. Install dependencies if necessary:
pip install pandas matplotlib yfinance
4. Run all cells in order.

These results demonstrate skills in data extraction and data visualization.
